Data Deletion

We hold no account data to delete. The files on your own devices are removed by uninstalling and deleting one folder.

Last updated 12 November 2026

Nothing on our side

There is no account or server-side profile, so there is nothing to ask us to delete.

On your devices

  1. Windows: uninstall Roundelay from Settings, then delete %APPDATA%\MultiPhonePlayer (this holds the host identity key; guests will then no longer recognise this host and must pair again).
  2. Android: uninstall the app, or use Settings › Apps › Roundelay › Storage › Clear data.
  3. Linux: delete ~/.config/multiphone-player (or $XDG_CONFIG_HOME/multiphone-player).
  4. macOS: the same folder under your home directory (~/.config/multiphone-player).

Saved Wi-Fi details

If you saved a hotspot name and password on a host, clear both fields in the host screen (or switch the option off and delete the data folder above). Guests never save them.

Revoking access

Guests are not remembered after they leave. To remove a connected device right away, use Disconnect beside it on the host screen.

Website and GitHub

To remove anything GitHub holds about you (for example an issue you opened), use your GitHub account settings or ask GitHub; the Roundelay authors cannot delete data on GitHub's behalf, but can delete issues you ask us to when it is within our power.
