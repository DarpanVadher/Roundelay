Cookie Consent

This website and the Roundelay app set no cookies and use no local storage for tracking, so there is no consent banner.

Last updated 12 November 2026

Website

The pages store nothing in your browser: no cookies, no local storage, no session storage, no fingerprinting and no third-party scripts. A consent banner would have nothing to ask about.

App

The app does not use cookies. Its only stored file is the host's identity key (see the Privacy Policy).

GitHub

If you follow a link to GitHub (for downloads or the source), GitHub's own cookie notice applies on its pages.

If this changes

If we ever add anything that needs consent, we will ask first, before it runs, and update this page.
